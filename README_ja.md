## 1. 概要

mktotp は、TOTP（時間ベースのワンタイムパスワード）シークレットを管理し、
多要素認証サービス用の認証トークンを生成するコマンドラインツールです。  
ローカルMCPサーバとしても機能し、MCPに対応したAgentツールから操作できます。

## 2. 機能

- PNG、JPEG、BMP、TIFF、SVG形式のQRコード画像ファイルを使って、TOTPシークレットを登録
- 登録されたシークレットの TOTP トークンを生成
- 登録されたすべてのシークレットを一覧表示
- シークレットの削除と名前変更
- ローカルMCPサーバとして、MCPに対応したAgentツールから操作可能  
  MCPサーバとして動作しているときは、シークレット文字列がLLMに送信されないように設計しています。  

## 3. 実行環境

このプロジェクトはパッケージマネージャにuvを使っています。  

uvのインストール方法は、次のページを参照してください。

- [Installing uv](https://docs.astral.sh/uv/getting-started/installation/)

## 4. インストール/使用方法

### 4-1. uv tool としてインストールする

uv環境にインストールして使います。  
CLIツールとして使う場合は、この方法を使ってください。  

#### 4-1-1. インストール

```bash
# gitリポジトリから直接インストール
uv tool install git+{リポジトリのURL}
```

インストール後は、`mktotp` コマンドを直接使えます。  

```bash
mktotp --help
```

#### 4-1-2. MCPサーバとして登録する

MCPサーバとして登録すると、Agentツールからも `mktotp` を操作できます。  
MCPサーバの登録手順は、使っているAgentツールのマニュアルを参照してください。  

```jsonc
{
  // MCPサーバとして登録する場合の設定例
  //
  // （注意）
  // Agentツールによって登録キーが異なります。
  // 詳細な手順は使っているAgentツールのマニュアルを参照してください。
  "mcpServers": {
    // uvを使ってmktotpをMCPサーバとして起動する設定
    "mktotp-uv": {
      "type": "stdio",
      "command": "mktotp",
      "args": [
        "mcp",
        "--mcp-server"
      ],
      "env": {}
    }
  }
}
```

### 4-2. Claude PluginとしてMCPサーバを登録する

mktotp は Claude Plugin としてインストールできます。  

```bash
# マーケットプレイスを追加
/plugin marketplace add zv-louis/zv-plugin-marketplace
# マーケットプレイスから登録
/plugin install mktotp-mcp@zv-plugins
```

## 5. CUIツールのコマンドオプション

### 5-1. 共通オプション

- `-v, --verbose LEVEL`: 出力の詳細度を設定（0: 通常、1: 詳細、2: デバッグ）
- `-s, --secrets-file FILE`: シークレットを保存する JSON ファイルのパス

### 5-2. `add` コマンド

新しいシークレットを追加します。  
`-f`（QRコード画像）と `-ss`（シークレット文字列）のどちらか一方の指定が必要です。  
どちらも指定しなかった場合はエラーになります。  
両方を指定した場合は `-f` が優先され、`-ss` は無視されます。  

- `-nn, --new-name`: シークレットの名前（必須）

既に同じ名前のシークレットが登録されている場合は、上書きされます。  

#### 5-2-1. QRコード画像ファイルから追加

QRコード画像から新しいシークレットを追加します。  

```bash
mktotp add -nn <新しい名前> -f <QRコード画像ファイル>
```

- `-f, --qrcode-file`: QRコードを含む画像ファイルのパス  
  PNG、JPEG、BMP、TIFF、SVG形式に対応しています（TIFFの拡張子は `.tiff` のみ）

アカウントと発行元（issuer）は、QRコードの内容から取得します。  
1枚の画像に複数のQRコードが含まれている場合は、すべてを登録します。  
2つ目以降のシークレット名には `_2`、`_3` ... が付きます（例: `<新しい名前>_2`）。  

#### 5-2-2. シークレットを直接登録 (CUIツールのみ)

シークレット文字列を直接指定して、新しいシークレットを追加します。  

```bash
mktotp add -nn <新しい名前> -ss <シークレット文字列> [-i <発行元>] [-a <アカウント>]
```

- `-ss, --secret-string`: Base32形式のシークレット文字列
- `-i, --issuer`: 発行元（issuer）。省略時はシークレット名を使います
- `-a, --account`: アカウント。省略時はシークレット名を使います

シークレット文字列に含まれる空白（4文字ごとの区切りなど）と末尾の `=` は、取り除いて保存します。  
Base32形式として不正な場合はエラーになります。  
エラーメッセージには、不正な文字の位置を先頭からの文字数で表示します（空白も数えます）。シークレットの値は表示しません。  

> `-ss` で指定した文字列は、シェルの履歴やプロセス一覧に残る可能性があります。

### 5-3. `get` コマンド

指定されたシークレット名の TOTP トークンを生成します。

```bash
mktotp get -n <シークレット名>
```

- `-n, --name`: 操作対象のシークレット名（必須）

### 5-4. `list` コマンド

登録されているすべてのシークレットを表示します。

```bash
mktotp list
```

### 5-5. `remove` コマンド

指定されたシークレットを削除します。

```bash
mktotp remove -n <シークレット名>
```

- `-n, --name`: 削除するシークレット名（必須）

### 5-6. `rename` コマンド

シークレットの名前を変更します。

```bash
mktotp rename -n <現在の名前> -nn <新しい名前>
```

- `-n, --name`: 現在のシークレット名（必須）
- `-nn, --new-name`: 新しいシークレット名（必須）

### 5-7. `mcp` コマンド

mktotpをローカルMCPサーバとして起動します。  
Agentツールからmktotpを操作できます。

```bash
mktotp mcp --mcp-server
```

`--mcp-server` オプションを指定しない場合は、MCPのツール一覧を出力します。

```bash
mktotp mcp
```

## 6. ファイル保存場所

デフォルトでは、シークレットは以下の場所に保存されます。

```text
~/.mktotp/data/secrets.json
```

`-s` オプションで別の場所を指定することもできます。

## 7. セキュリティに関する注意

- シークレットファイルは機密情報を含むため、所有者以外が読み書きできない権限で保護してください。mktotp は保存時に、所有者のみが読み書きできる権限（Unix系OSでは 600）を自動で設定します。  
- バックアップを作成する際は、暗号化されたストレージを使うことを推奨します。  
- 不要になったシークレットは `remove` コマンドで削除してください。
